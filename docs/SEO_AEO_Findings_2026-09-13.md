## What the target searches show today

I ran the report's ten target queries through a US web search (the same kind of index Bing, Perplexity and Gemini draw on). Plain reading:

We already show up for the aerospace-specific phrasings. "Aerospace safety analysis software ARP 4761A" returns the home page on the first page. "Common cause analysis aerospace" returns the home page. "Aircraft safety analysis tools" returns both the home page and the fault tree guide. That is the Google 100/100 the report measured.

We do not show up for the generic product phrasings: "fault tree analysis software," "FMEA software aerospace," "aerospace safety engineering software," "ARP 4754B software." Those pages are owned by the incumbent tool vendors (Isograph, Relyence, ALD, PTC Windchill, Ansys medini) and by explainer content from Jama Software, AFuzion, ConsuNova and Visure. The pattern is clear: the vendors win on product pages, and the consultancies win on "what is ARP 4761A" explainers. Our guide pages now answer those definitional questions directly, which is the lever the answer engines use, but they are a week old; expect a month before it shows in the Vector score.

Two observations worth acting on later, not now: the ARP 4754B query is answered mostly by explainer articles, not tools, so a fuller "ARP 4754B explained" section on our guide page would compete where there is little vendor competition; and the "aerospace safety engineering software" query surfaces a couple of low-quality "best 10 tools" listicles, which is what a real directory listing (below) displaces.
